Puntos a resolver con el profesional antes de publicar:

1. Razón social / titular, CUIT y domicilio de TURNUP (hoy figuran como `[COMPLETAR]`).
2. Inscripción de la base de datos en el **Registro Nacional de Bases de Datos Personales**
   (AAIP, trámite a distancia) y si corresponde una o varias bases.
3. **Transferencia internacional** de datos: la base y el hosting funcionan con proveedores cuyos
   servidores pueden estar fuera de Argentina (Neon, Netlify, proveedor de email). Definir la base
   legal (consentimiento, cláusulas contractuales) según el art. 12 de la Ley 25.326.
4. Normas de defensa del consumidor aplicables a la suscripción (información previa, mecanismo de
   baja simple, facturación) y jurisdicción.
5. Plazos de conservación de datos y de registros de auditoría.
