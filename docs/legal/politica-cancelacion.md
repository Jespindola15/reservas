# Política de cancelación (modelo para complejos) — BORRADOR (no definitivo)

_Modelo orientativo. Cada complejo define la suya en **Panel → Página pública → Política de
cancelación** y el plazo de cancelación online en **Ajustes**. Revisar con un profesional._

1. **Cancelación online**: el jugador puede cancelar desde su enlace privado hasta **[X horas]**
   antes del inicio del turno. Pasado ese plazo, debe comunicarse con el complejo.
2. **Señas**: si el complejo pidió seña, se devuelve si la cancelación se hace dentro del plazo;
   fuera de plazo, [COMPLETAR: se pierde / se reprograma / a criterio del complejo].
3. **Lluvia o fuerza mayor** (canchas descubiertas): el complejo puede cancelar o reprogramar sin cargo
   para el jugador. [COMPLETAR].
4. **Ausencias**: los turnos no cancelados a los que nadie se presenta pueden registrarse como
   ausencia y el complejo puede limitar futuras reservas online de ese contacto.
5. **Cancelación por el complejo**: el complejo avisa por el medio de contacto informado y, si había
   seña, la devuelve o reprograma.
